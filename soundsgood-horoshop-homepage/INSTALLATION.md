# Установка и проверка

## 1. HTML

Скопируйте только содержимое файла `src/home-block.html` в пользовательский HTML-блок главной страницы.

Не добавляйте полный HTML-документ и не вставляйте теги:

```html
<!DOCTYPE html>
<html>
<head>
<body>
```

## 2. CSS

Добавьте содержимое `src/client.css` в конец пользовательского `client.css`. Все селекторы проекта начинаются с `sg-`, поэтому стили не должны изменять штатные элементы Хорошопа.

## 3. Проверка перед публикацией

- каталог и все категории открываются без 404;
- кнопки сервиса и тендеров ведут на нужные страницы;
- на странице только один `h1`;
- текст не выходит за пределы карточек;
- кнопки доступны с клавиатуры;
- мобильная версия корректна на ширине 320–430 px;
- изображения и скрипты со сторонних сайтов отсутствуют;
- текущий `client.css` сохранен отдельно до внесения изменений.

## 4. Откат

Удалите HTML-блок и добавленную часть CSS либо восстановите резервную копию `client.css`.
