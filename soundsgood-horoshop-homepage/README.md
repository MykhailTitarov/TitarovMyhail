# SoundsGood — блок главной страницы для Хорошоп

Оригинальный адаптивный HTML/CSS-блок для главной страницы интернет-магазина [SoundsGood](https://soundsgood.com.ua/), подготовленный для платформы Хорошоп.

Код не копирует тему, скрипты, аналитику, изображения или фирменные материалы Thomann. Сайт Thomann использовался только как ориентир по структуре крупного музыкального интернет-магазина.

## Состав проекта

```text
soundsgood-horoshop-homepage/
├── README.md
├── src/
│   ├── home-block.html   # HTML для пользовательского блока Хорошопа
│   └── client.css        # изолированные стили с префиксом sg-
└── docs/
    ├── .nojekyll
    └── index.html        # автономный предпросмотр
```

## Установка в Хорошоп

1. Сохраните резервную копию текущего `client.css`.
2. Откройте `src/home-block.html` и скопируйте разметку в пользовательский HTML-блок главной страницы.
3. Откройте `src/client.css` и добавьте стили в конец пользовательского `client.css` активной темы.
4. Не вставляйте в HTML-блок теги `<!DOCTYPE>`, `<html>`, `<head>` и `<body>`.
5. Проверьте, что на главной странице остается только один основной заголовок `h1`. При наличии другого `h1` замените заголовок `.sg-hero__title` на `h2`.
6. Перед публикацией проверьте страницу на ширине 320, 375, 768, 1024 и 1440 пикселей.

## Предпросмотр

Откройте `docs/index.html` в браузере. Это автономный предпросмотр блока, а не полная копия темы Хорошопа. На рабочем сайте итоговый вид может немного отличаться из-за глобальных стилей темы.

## Что учтено

- все CSS-селекторы изолированы префиксом `sg-`;
- отсутствуют внешние JavaScript-библиотеки;
- код не вмешивается в корзину, поиск, личный кабинет или каталог Хорошопа;
- предусмотрены адаптивные состояния для компьютеров, планшетов и телефонов;
- используются рабочие ссылки на каталог, категории, сервис и тендеры SoundsGood;
- добавлена поддержка `prefers-reduced-motion`;
- внешние `canonical`, Open Graph, Schema.org и аналитические теги не используются.

## Важное ограничение

Этот проект оформляет только контентную часть главной страницы. Шапка, поиск, меню, корзина, личный кабинет, каталог товаров и оформление заказа должны оставаться штатными компонентами Хорошопа.
