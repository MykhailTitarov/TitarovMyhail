# product_names.py — сортировка товаров и правильные названия UA/RU через Claude API

Скрипт берёт список товаров (CSV или JSON), отправляет «сырые» названия в Claude API
и получает для каждого товара грамотное, единообразное название и категорию
на украинском и русском языках. Затем сортирует товары с правильным порядком букв
кириллицы и сохраняет результат.

## Установка

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...      # ключ из https://platform.claude.com
```

## Быстрый старт

```bash
# CSV -> CSV, сортировка по умолчанию: категория (uk), затем название (uk)
python product_names.py --input examples/products_sample.csv --output products_sorted.csv

# JSON -> JSON, сортировка по русской категории, затем по цене по убыванию
python product_names.py -i examples/products_sample.json -o out.json --sort-by "category_ru,-price"

# Без обращения к API: только очистка названий и сортировка (проверить файл, не тратя токены)
python product_names.py -i products.csv -o out.csv --offline
```

Если первое поле сортировки начинается с `-`, пишите через `=`: `--sort-by=-price`.

## Входной файл

Поддерживаются CSV (разделитель определяется автоматически) и JSON (список объектов
или объект с ключом `products` / `items` / `data`). Колонки определяются автоматически
по названиям, либо задаются явно:

| Данные    | Автоопределение (без учёта регистра)                         | Опция            |
|-----------|---------------------------------------------------------------|------------------|
| название  | name, title, product, назва, название, наименование, товар    | `--name-col`     |
| категория | category, категорія, категория, група, группа, раздел, розділ | `--category-col` |
| бренд     | brand, бренд, виробник, производитель, manufacturer           | `--brand-col`    |
| цена      | price, ціна, цена, стоимость, вартість                        | `--price-col`    |

Все остальные колонки сохраняются без изменений.

## Выходной файл

К каждому товару добавляются поля:

| Поле          | Содержимое                                                        |
|---------------|-------------------------------------------------------------------|
| `name_uk`     | название на украинском                                            |
| `name_ru`     | название на русском                                               |
| `category_uk` | категория на украинском                                           |
| `category_ru` | категория на русском                                              |
| `brand`       | бренд в оригинальном написании                                    |
| `comment`     | замечание модели, если исходное название непонятно (иначе пусто)  |

CSV пишется в UTF-8 с BOM, чтобы Excel сразу правильно показывал кириллицу.

## Правила, по которым модель формирует названия

Правила заданы в `SYSTEM_PROMPT` внутри скрипта и их можно править под свой каталог:

- структура «Тип товара Бренд Модель, характеристики» (Смартфон Samsung Galaxy A55 8/256 ГБ, чёрный);
- бренды и модели не транслитерируются и не переводятся;
- единицы измерения через пробел (500 мл, 1,5 л), кавычки «ёлочки»;
- убирается мусор («АКЦИЯ», «NEW», коды поставщика, лишние пробелы);
- исправляются орфография и грамматика, в русском используется «ё», в украинском — ґ, є, і, ї, апостроф;
- характеристики, которых нет в исходном названии, не придумываются.

## Сортировка

`--sort-by` принимает список полей через запятую, префикс `-` означает «по убыванию».
Доступны `name_uk`, `name_ru`, `category_uk`, `category_ru`, `brand`, `price`
и любая колонка входного файла. Поля с суффиксом `_ru` сортируются по русскому алфавиту,
остальные текстовые — по украинскому (Г < Ґ, Е < Є, И < І < Ї < Й). Числа внутри
строк сравниваются как числа (A2 < A10), регистр не учитывается, латиница идёт после кириллицы.
`price` понимает форматы «13 999», «1 299,50 грн», «1,299.50»; пустая цена уходит в конец.
`--no-sort` сохраняет исходный порядок.

## Параметры API

| Опция           | По умолчанию                 | Описание                                                        |
|-----------------|------------------------------|-----------------------------------------------------------------|
| `--model`       | `claude-opus-5-5`            | модель Claude                                                   |
| `--effort`      | `medium`                     | глубина рассуждений: low / medium / high / xhigh / max          |
| `--batch-size`  | 20                           | сколько товаров уходит в одном запросе                          |
| `--workers`     | 2                            | параллельных запросов к API                                     |
| `--cache`       | `.product_names_cache.json`  | кэш ответов: повторный запуск не платит за обработанные товары  |
| `--no-cache`    |                              | не читать и не писать кэш                                       |
| `--no-fallback` |                              | отключить серверный fallback на запасную модель при отказе      |

Ответ модели принимается только в строгой JSON-схеме (структурированный вывод),
поэтому «кривых» ответов не бывает: либо все товары пакета обработаны, либо скрипт
сообщает об ошибке. Системный промпт кэшируется на стороне API (prompt caching),
что снижает стоимость при большом каталоге.

## Использование как библиотеки

```python
from product_names import process_products, sort_products, read_products

rows = read_products(Path("products.csv"))
rows = process_products(rows, name_col="name", category_col="category", brand_col="brand")
rows = sort_products(rows, "category_uk,name_uk")
```
